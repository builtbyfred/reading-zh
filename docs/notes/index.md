# 短摘录 / 笔记

完整译文放在对应主题目录，例如 [AI / Agent](/ai-agents/) 或 [自身成长](/growth/)。这里放更短的东西：一段摘录、一张术语卡片、读完两篇之后的对照。

这个目录目前是占位。还没有笔记。

## 和文章页的差别

- 文章页对应一篇原文，状态用「待译」「摘要」或「译文」。
- 笔记可以只讲一个点，仍然要链回来源，并标明非官方。
- 术语的统一写法写在仓库根目录 `CONTRIBUTING.md` 的术语表里。某一条稳定下来、值得单独成页时，再摘到这里。

## 添加一篇笔记

用 `docs/notes/<slug>.md`。若笔记针对某篇文章，frontmatter 仍写 `source` 和 `source_url`，页面上方会自动出现「非官方译文」提示。然后更新本页和侧栏。
