# 自身成长

这里放和模型没有直接关系、或不全是技术的阅读：习惯、注意力、写作、决策、职业、作品。格式与 [AI / Agent](/ai-agents/) 相同：链到原文，在这里写中文译文、摘要或笔记，并标明非官方。

这个目录目前是占位。还没有文章。

## 以后可以怎么分

不必现在就拆子目录。第一篇直接放在 `docs/growth/<slug>.md`。篇数变多之后，再按主题在本页分组，例如：

- 习惯与注意力
- 写作与表达
- 决策
- 职业与作品

## 添加第一篇时

1. 新建 Markdown，写好 frontmatter（见仓库根目录 `CONTRIBUTING.md`）。
2. 在本页加上标题、原文链接和一两句为什么读。
3. 在 `docs/.vitepress/config.ts` 的「自身成长」侧栏里登记链接。

没有想译的原文时，不必为了填满栏目去建空页面。
