# 经济指数：学习曲线

**非官方译文。** 官方原文：[Economic Index: Learning curves](https://www.anthropic.com/research/economic-index-march-2026-report)（Anthropic · Research）。

## 导读

这份报告用 2026 年 2 月 5 日至 12 日的 Claude 用量，接上上一份报告在 2025 年 11 月建立的经济原语；样本在 Claude Opus 4.5 发布三个月之后，并与 Claude Opus 4.6 的发布重合。前半记录用法变化：Claude.ai 上任务更分散、个人用途上升，API 上编程更集中。后半看学习曲线：注册至少六个月的用户成功率更高，而且这不能只用他们选了不同 task（任务）来解释。原文发表于 2026 年 3 月 24 日。

## 译文

Anthropic 经济指数用隐私保护的数据分析系统，追踪 Claude 在经济中如何被使用。它是尽早理解 AI 经济影响的努力的一部分，以便研究者和政策制定者有足够时间准备。

这份最新报告研究 2026 年 2 月的 Claude 用量，建立在上一份报告引入的经济原语框架之上（上一份用的是 2025 年 11 月的数据，见[经济指数：经济原语](./economic-index-primitives)）。样本覆盖 2 月 5 日至 2 月 12 日，距 Claude Opus 4.5 发布三个月，并与 Claude Opus 4.6 的发布重合。

首先记录相对此前报告用量有何变化：augmentation（增强）的比率，也就是 AI 补充用户能力的协作式交互，在 Claude.ai 和 API 流量里都略有上升。在 Claude.ai 上，用量更加多样化，前 10 项任务占用量的份额低于 2025 年 11 月。由于这种多样化，Claude.ai 上的平均对话所对应的任务，薪资略低于此前报告。

然后聚焦 Claude 对劳动力市场和更广经济的影响的一个重要决定因素：采用 Claude 的学习曲线。证据表明，资历高的用户已经形成习惯和策略，使他们能更好地驾驭 Claude 的能力。确实，更有经验的用户不仅尝试价值更高的任务，也更可能在对话中引出成功的回复。

#### 自上一份报告以来有什么变化

第一章回看 2026 年 1 月发布的上一份经济指数报告，发现：

- Claude.ai 上的用途更加多样化。编程任务继续从 Claude.ai 上的增强式使用，迁到第一方 API 流量里更自动化的工作流（见脚注 1）。本报告里 Claude.ai 的用量没那么集中：前 10 项任务占 2 月全部流量的 19%，11 月是 24%。尽管如此，本样本里几乎所有任务都至少在此前某一次样本里出现过。大约 49% 的工作，其至少四分之一的任务曾用 Claude 完成过。
- Claude 的采用扩到了薪资更低的任务。随着用途多样化，在 Claude 上完成的工作的平均经济价值（以相关职业中美国工人所得工资衡量）略有下降。这在机制上由围绕体育、产品比较和家庭维护的个人查询上升造成。这一模式与标准的「采用曲线」相符：早期采用者偏好编程这类特定的高价值用途，较晚的采用者承担范围广得多的任务。
- 全球用量的不平等持续存在。用量仍然高度集中：前 20 个国家占全部人均用量的 48%，此前是 45%，凸显全球采用的持续差距。不过，Claude 的人均用量在美国境内继续收敛：用量最高的 10 个州所占用量份额，自上一份报告以来从 40% 降到 38%。

#### 学习曲线

经济指数的一项核心发现是，Claude 的早期采用非常不均：高收入国家用得更密，在美国境内则是知识工人更多的地方用得更密，并且集中在相对小的一组专门任务和职业上。

一个重要问题是，采用的不平等可能如何决定 AI 的收益落在何处、落在谁身上。例如，如果有效使用 AI 需要互补的技能和专门知识（上一份报告论证过这一点），并且这类技能可以通过使用和试验获得，那么早期采用的收益可能自我强化。

第二章考察用户看起来如何塑造他们从 Claude 得到的价值：他们如何把模型能力配到手头的任务，以及用量模式和结果如何随在平台上的经验变化。

- 模型选择与任务相配。用户把最强的模型档 Opus 用于劳动力市场上通常工资更高的任务。例如在付费的 Claude.ai 用户中，Opus 用于编程任务的比率比平均高 4 个百分点，用于辅导相关任务的比率比平均低 7 个百分点。对 API 用户，这种模型切换大约剧烈一倍。
- 资历更高，成功也更高。总体上，最资深的 Claude 用户更常把它用于更高教育水平的任务，更少用于个人用途。例如，使用 Claude 已有 6 个月或更久的人，个人对话少 10%，其输入所反映的教育水平高 6%。最突出的是，这一高资历组的对话成功率高 10%。这一关联不能由他们的任务选择、来源国或其他因素解释。这可能反映早期采用者的精深程度，也可能是干中学的证据：人们通过经验变得更会使用 Claude。

### 自上一份报告以来有什么变化

#### Claude.ai 上用途的多样化

首先看 Claude 被要求执行的任务种类。使用的是隐私保护系统，它可以在不揭示单条记录内容的情况下，在聚合层面描述行为（系统见 [Clio 论文](https://arxiv.org/abs/2412.13678)）。从 Claude.ai（面向消费者的网页产品）和第一方 API（面向开发者、把 Claude 集成进产品和流程的接口）各抽样 100 万次对话（见脚注 2）。

编程仍是各平台上最常见的用途，与计算机和数学职业相关的任务占 Claude.ai 对话的 35%（见附录，脚注 3）。不过从 2025 年 11 月到 2026 年 2 月，Claude.ai 上的用途变得不那么集中：最常见的 10 项 O*NET 任务从占对话的 24% 降到只有 19%（图 1.1）。

集中度的这一下降，部分反映编程任务从 Claude.ai 迁到第一方 API。在那里，Claude Code 已经占抽样流量的很大份额。Claude Code 的智能体式架构把编程工作拆成更小的 API 调用，这些调用被标成不同的任务。因此，尽管编程在 API 流量中的总份额增长了，它是铺在许多任务类别上，而不是集中在少数几项。结果是，尽管编程活动涌入，API 里的任务集中度大致持平。

[图 1.1](https://www-cdn.anthropic.com/images/4zrzovbb/website/e0294de133e1d71da05fa21063aa3e9f904dbe82-4417x2496.png)：各平台前 10 项任务的用量份额随时间的变化，Claude.ai 与 1P API。按平台和报告版本，分到最常见的十项 O*NET 任务的对话份额。

代码迁出 Claude.ai 不是推动集中度下降的唯一因素。下降的一部分来自两个时期用途组合的变化。课程作业从占对话的 19% 降到 12%，个人使用从 35% 升到 42%。课程作业的一部分下降可以用学业日历解释：样本期内，一些国家的学生在放寒假（见脚注 4）。与此同时，大约从 2 月开始的注册增加，带来了更多随意的 AI 用户。

[原图](https://www-cdn.anthropic.com/images/4zrzovbb/website/1e2365b2b158ffb9a7317c331ec64a06c40750f4-4417x2496.png)：2025 年 11 月和 2026 年 2 月 Claude.ai 上的工作、个人和课程作业用量。被识别为与工作、个人或课程作业相关的 Claude.ai 对话份额。

尽管 Claude 的工作任务铺得更开，其中几乎所有都在数据里见过。上一份报告指出，49% 的工作至少有四分之一的任务曾用 Claude 完成。这一次抽取里，该累计估计几乎没变（附录图 A.2）。本报告的数据里，新出现的 O*NET 任务比上一份报告少得多。

自第一份报告以来，对话被分成五种交互类型：指令式、反馈循环、任务迭代、校验和学习，并归进两大类：automation（自动化）和增强（见脚注 5）。图 1.3 显示 Claude.ai 上的增强略有上升。这由校验和学习模式的小幅抬升推动。附录图 A.3 显示，1P API 数据里的自动化急剧下降。

[图 1.3](https://www-cdn.anthropic.com/images/4zrzovbb/website/230e2c65024356e0a02498fc4a41330d09d0a373-4418x2496.png)：Claude.ai 的协作模式份额。各份经济指数报告中 Claude.ai 的协作模式频率。

API 平台继续获得相对更高的计算机与数学任务份额（按职业类别的用量份额见附录）。自 2025 年 8 月以来，这一类任务的份额在 API 上升了 14%，在 Claude.ai 下降了 18%。如在关于劳动力市场影响的报告里所指出的，预期这种从 Claude.ai 到 API 的迁移，可能标出相关工作更迫近的转型。Claude.ai 上与管理职业相关的任务从占其流量的 3% 增到 5%，来自分析类任务（例如准备投资备忘录）和回答客户问题的混合。

衡量 Claude 上所做任务组合变化的另一种方式，是看任务平均价值的变化。任务价值定义为执行该任务的美国工人的平均时薪（图 1.4，见脚注 6）。Claude.ai 上这项任务价值估计从 49.3 美元略降到 47.9 美元，主要因为简单事实问题增加（例如体育结果、天气），以及编程转向 API 而减少。如上一份报告所述，在 Claude 上看到的任务往往需要更高教育。该图显示，这些任务的工资也往往高于美国全国平均。

[图 1.4](https://www-cdn.anthropic.com/images/4zrzovbb/website/29ee0ffb64d1246127349ff0912eba75a34ae668-4417x2496.png)：各版本、各平台的平均任务价值变化。该图用 O*NET 框架估计在 Claude.ai 和 1P API 上执行的任务的美元价值。任务价值估计为做该任务的工人所得的平均时薪。

变化虽小，上一份报告与本报告之间若干原语的变化，抓住了 Claude.ai 上任务复杂度的类似下降。理解人类输入所需的平均教育年限从 12.2 年降到 11.9 年，用户给予 AI 更多自主，人类独自做该任务所需的时间下降了大约 2 分钟。有一项变化表面上方向相反：由 Claude 完成的任务被判定为，对没有 AI 的人类来说略更不可能完成。

[原表](https://www-cdn.anthropic.com/images/4zrzovbb/website/011a8cb48accd97b47b67b67f0f0e5337ff784b1-4417x1792.png)：关键原语的变化。该表给出 Claude.ai 上的平均原语，并与上一份经济指数报告比较。除「人类单独所需时间」为 p < 0.05 外，所有差异在 p < 0.001 上统计显著。这些原语的定义见附录。表中各格的具体均值除正文已写的教育年限（12.2 年到 11.9 年）和人类单独时间（约少 2 分钟）外，只出现在原图里，此处不另补数字。

#### 正在浮现的自动化模式

任务迁到 API 之后，可能更多地暴露于自动化。API 工作流远更可能是指令式的，更不需要人在回路中。上一份报告强调，客户服务任务（例如针对付款和账单问题的自动支持）在 API 数据里很常见。它们推高了客户服务代表的观察暴露：Claude 被记录在自动化工作流里做了他们很高份额的任务，因此随着 AI 扩散，这些工作可能更可能发生变化。

这里突出两类在 2 月比三个月前出现得更频繁、在最新样本里份额至少翻倍的 API 工作流（见脚注 7）：

- 商务销售与外联自动化：销售赋能内容生成、B2B 线索资格研究、客户数据充实、冷邮件起草。
- 自动交易与市场操作：监测市场或头寸、提出具体投资、向交易员告知市场状况，以及相关任务。

#### 再看地理收敛

上一份报告指出，按一地劳动年龄人口调整用量的 Anthropic AI 用量指数（AUI），在美国各州之间迅速收敛：起初人均用量较低的州采用更快。

图 1.6 的左面板显示，这一收敛在最新数据里继续，但速度更慢。从 2025 年 8 月到 2026 年 2 月，人均用量流向用量最高的五个州的份额从 30% 降到 24%。基尼系数自 2025 年 8 月以来下降，不过收敛速度已经放缓。更新上一份报告的估计后，按这一速度，各州大约会在 5 到 9 年内达到大致相等的人均用量，而不是 2 到 5 年（见脚注 8）。

[图 1.6](https://www-cdn.anthropic.com/images/4zrzovbb/website/37649d82a90d0583cff85a462f2d4da4f31767f2-4418x2496.png)：地理收敛。该图是 Anthropic 用量指数的洛伦兹曲线，左面板为美国各州，右面板为各国。

在各国（右面板），模式相反：用量变得略更集中，同一时期基尼系数上升。人均使用 Claude 最多的国家现在占总体用量的更大份额，前 20 个国家从人口调整后用量的 45% 增到 48%。

### 学习使用 AI

本章聚焦用量的两个特征，它们反映人们如何部署 AI、并学习与 AI 一起工作：模型选择，以及长期用户的习惯。

首先，通过研究人们何时选择 Opus（表现最强的模型档），照见对智能的需求。关于 AI 用户如何在不同模型之间选择、如何权衡速度、表现和成本，所知甚少。如果用户在按手头任务校准，就应该看到 Opus 集中在更难、价值更高的工作上。

接下来按资历研究用量如何不同，比较不同时间注册的用户。这照见学习曲线：有经验的用户是否随时间变得更好？他们的用量有何不同？发现与干中学一致。资历更高的用户不仅在对话中有更高的成功，也更多地与 Claude 协作，带来更有挑战的任务，并且更可能把 Claude 用于工作、用于更广的一组任务。

#### 模型选择

不同的 Claude 模型档（Haiku、Sonnet 和 Opus）在成本、速度和表现上提供权衡。Opus 档用的 token 最多，擅长复杂任务，但在 API 上每个 token 的价格更高。如果用户知道这一点，并且在意成本和用量上限，他们就应该把最复杂、最有价值的任务带给 Opus，把更简单的任务交给其他模型。数据里大体上观察到的就是这样。

下图 2.1 显示，对可以使用全部模型档的付费 Claude.ai 账户，计算机与数学任务（例如编写软件）有 55% 使用 Opus，教育任务是 45%。技术用户可能注意到表现差异，并主动从默认的 Sonnet 换走。或者注重效率的用户可能学会在更简单的任务上用 Sonnet，以免碰到用量上限。与此相关，这里的差别也可能反映：大多数教育任务对 Sonnet 已经相当容易，或者学生更可能在意用量上限。

[图 2.1](https://www-cdn.anthropic.com/images/4zrzovbb/website/afba3decf70429553b7c06b0aa1385f173f1ea7c-4417x2497.png)：模型选择与职业领域。该图显示，付费 Claude.ai 用户选择 Opus 档的多少，如何取决于任务所在的职业领域。在这个样本里，总体用量的 51% 是 Opus，计算机与数学用量的 55%（高 4.4 个百分点）是 Opus。

下图 2.2 以更细的方式显示这一点。当用户执行与更高薪工作相关的任务时，他们更常用 Opus。例如在 Claude.ai 上，软件开发人员任务有 34% 涉及 Opus，导师任务只有 12%。总体上，任务的时薪每多 10 美元，Claude.ai 用户中使用 Opus 的对话份额增加 1.5 个百分点。1P API 流量对任务复杂度的反应大得多。它的斜率大约是两倍，任务价值每增加 10 美元，Opus 份额增加 2.8 个百分点。部署程序化工作流的用户，可能比网页用户更有理由在模型之间切换。

[图 2.2](https://www-cdn.anthropic.com/images/4zrzovbb/website/f33cf74122b06a2608c94b043dfdd126d6d23af7-4417x2497.png)：模型选择与职业。该图显示用户选择 Opus 档的频率如何取决于任务所关联的职业。每个点是一个职业（横轴）及其 Opus 份额（纵轴）。左面板是 Claude.ai 用户，右面板是 1P API 用户。

#### 学习曲线

第一个 Claude 模型于 2023 年 3 月发布。此后 Claude.ai 和 API 上的用户群都增长很快。最新样本混合了不同用户：有的在 Claude 第一次发布时就注册，有的就在测量用量的前一天注册。一个人使用 Claude 的资历如何塑造他的体验（见脚注 9）？

表 2.1 给出低资历与高资历用户的差别。高资历组定义为至少在 6 个月前注册 Claude，其余人为低资历用户（见脚注 10）。高资历用户更可能用 Claude 迭代自己的工作，并且远更少通过指令式使用模式委托更大的责任。他们把 Claude 用于工作的可能性高 7 个百分点，并把 Claude 用于往往需要更高教育水平的任务。最后，他们的用量在某些任务上不那么集中。前 10 项 O*NET 任务占高资历组用量的份额略低（20.7%，低资历组为 22.2%）。

[表 2.1](https://www-cdn.anthropic.com/images/4zrzovbb/website/d8ddbda7a54e33e61e4c467d0cd7238a169cf3be-4418x2497.png)：高资历与低资历用户的差别。该表给出高资历和低资历用户的平均特征。高资历用户定义为在本次抽取之前至少六个月注册 Claude 的人。表中其余单元格只出现在原图里；正文写明的差别是：用于工作的可能性高 7 个百分点，前 10 项任务份额为 20.7% 对 22.2%。

下面更深入地看上面讨论过的两个原语：每段对话所关联的人类受教育年限，以及用于个人用途的记录份额。

左面板显示，Claude 使用每多一年，理解人类提示所需的受教育年限增加将近 1 年。右面板同时显示，个人使用下降：一年前注册的人把 38% 的对话用于个人用途，最新用户是 44%。

[原图](https://www-cdn.anthropic.com/images/4zrzovbb/website/582b6323dd78604025221b88eae377d2fd717a03-8192x4632.png)：资历如何与教育年限和个人使用相关。该图是两幅分箱散点。左面板是人类教育年限相对注册后天数。右面板是个人用途对话的百分比相对注册后天数。

对一项快速进步的通用技术，用户群里的这些模式可能由若干因素造成。高资历用户是自我选择的，这里的差别可能反映稳定的特征。例如他们可能是计算机程序员，更可能成为早期采用者。此外存在固有的存活偏差：在抽取前一年注册的人，可能正从使用中看到正的结果。观察不到一年前注册、但已经不再使用 Claude 的人。

这些发现与经济原语报告里看到的相呼应：收入较低、教育程度较低的国家，在某些情形下反而表现出更复杂的使用。最早的采用者往往有高价值的技术用途。在采用率低得多的较穷国家，这些早期采用者仍然主导用户群。

当 AI 扩散到人口中更广的份额时，更随意的使用才会出现。确实，在请求簇里，平均资历最高的任务包括：AI 研究、Git 操作、修订书稿，以及创业融资。平均资历最低的任务有更简单的流程，例如写俳句、查体育比分，以及为聚会建议食物（见脚注 11）。

#### 经验效应

下图 2.4 更进一步探讨这些关系，用对数层级的数据，以便对对话特征做细粒度控制。上面板的设定（1）是一个简单的二元回归，结果变量是任务成功，预测变量是长资历指示。成功是 Claude 对对话是否成功的评估，上一份报告里有说明。该图显示，长资历用户有成功对话的可能性大约高 5 个百分点。

这可能反映资历更高的用户更会写提示。但如果它反映的是他们带给 Claude 的任务不同、而这些任务更可能成功呢？

在设定（2）里，放入具体 O*NET 任务和请求簇的固定效应。这相当于在同一项定义狭窄的任务内部比较高资历和低资历用户，而不是跨任务比较。例如有一个请求簇叫「为特定公司做公司财务分析、估值和建模」。固定效应在该簇内部比较高资历和低资历用户，在每一个其他簇里也同样比较。只有当长资历用户平均而言在这些任务内部的比较中更成功时，才会观察到正的系数。这一控制使效应有所缓和，把它带到更接近 3 个百分点。

[图 2.4](https://www-cdn.anthropic.com/images/4zrzovbb/website/3077977b4ac5b82989e610e914e031c0ed2e1099-4417x2497.png)：经验与成功的关联。该图是把二元成功度量对高资历指示做回归的结果，控制越来越严。系数以百分点给出，须线是 95% 置信区间。「任务固定效应」表示 O*NET 任务和请求簇的固定效应。完整控制再加上模型、用途和国家固定效应。

最后问这一关系是否受以下因素影响：资历更高的用户选择不同模型、用不同语言交流、有不同用途，或在不同国家登录。这一回归给出的高资历影响略高，表明在完整控制下成功率高 4 个百分点。

这些结果提示，高资历用户在与 Claude 的对话中有更多成功，而这不是由语言或所执行的任务这类简单因素造成的。一个耐人寻味的可能解释是，这些用户更好地学会了从 AI 里取出他们想要的东西。熟练使用这些平台，可能是成功的一个关键决定因素，而且它看起来随经验而放大。

### 讨论

本报告回看用来追踪 Claude 用量的核心度量，并第一次分析了模型选择和成功。自 2025 年 8 月以来，1P API 用量变得更集中，前 10 项 O*NET 任务现在占流量的 33%，此前是 28%。另一方面，自 2025 年 11 月的数据以来，Claude.ai 的任务更加多样化。美国低用量州的更快采用仍在继续，不过速度比上一份报告慢。低采用国家又略为落后了一些。

有了这份报告，可以开始勾勒各种经济原语如何变化。课程作业占用量的份额下降，个人对话增加。还注意到 Claude.ai 上提示的总体复杂度略有下降：Claude.ai 的对话表现出没那么精深的输入，以及更短的估计完成时间。

总体上，Claude 被用于高价值、复杂的工作，这些工作并不能广泛代表美国经济。但随着用户群增长，报酬较低的任务在流量里的份额略为变大。任务的平均价值（以与这些任务相关的职业中工人所得的估计工资衡量）自第一份报告以来在 Claude.ai 上下降，在 API 用户中上升。在两个界面上，用户都把最复杂的任务带给更强的模型档 Opus。这一拐点对 API 客户更强。

更有经验的用户倾向于更协作地使用 Claude，更多地出于与工作相关的原因，用在更复杂的任务上，并且有更多成功。这推开了去年的一个假说：自动化使用可能在更有经验、更精深的用户里更典型。实际发现是，最进阶的用户更可能与 Claude 迭代。这也与干中学一致：使用 AI 的时间越长，驾驭它就变得越有效。

当然，另一种解读是这些结果由同期群效应或存活偏差驱动。早期采用者可能更技术化。继续使用 Claude 的人，可能是那些手上的任务恰好是它特别胜任的人。但控制严格的回归排除了这种混淆的简单版本，例如长资历用户带来的是不同种类的任务。随着时间推移，将能更干净地把同期群和存活偏差从干中学里分离出来。

观察到的成功率差异可能加深劳动力市场的不平等。经济学家早就指出技能偏向性技术变化的可能：创新提高高技能工人的工资，同时压低其他人的工资。本报告的分析指出一条渠道，这种技能偏向性的转型可能已经在展开：带着高技能任务的早期采用者，与 Claude 的成功交互多于较晚的、技术性较低的采用者。这些早期采用的用户，可能同时是最暴露于 AI 驱动的扰动的人，也是在这最初的、增强式采用浪潮里最受 AI 帮助的人。

## 笔记

- 前 10 项任务在 Claude.ai 上从 11 月的 24% 降到 2 月的 19%，课程作业从 19% 降到 12%，个人用途从 35% 升到 42%。API 一侧讨论里写前 10 项现为 33%，8 月是 28%。编程份额自 8 月以来在 API 上升 14%、在 Claude.ai 下降 18%，原文用的是百分数而不是百分点。
- 资历效应在摘要和回归里口径不同：摘要写高资历组成功率高 10%；回归里大约高 5 个百分点，加上任务固定效应后接近 3 个百分点，完整控制下高 4 个百分点。摘要还写个人对话少 10%、输入的教育水平高 6%。
- 美国各州收敛变慢了：上一份报告的区间是 2 到 5 年，这次更新为 5 到 9 年（有权重 5 年，无权重 9 年）。用量最高的五个州所占人均用量从 30% 降到 24%。国家之间则更集中，前 20 国从 45% 到 48%。
- 付费 Claude.ai 上，Opus 占总体用量 51%，计算机与数学任务 55%（高 4.4 个百分点）；摘要里编程比平均高 4 个百分点、辅导低 7 个百分点。时薪每高 10 美元，Opus 份额在 Claude.ai 增加 1.5 个百分点，在 API 增加 2.8 个百分点。
