# 开发 Computer Use 模型

**非官方译文。** 官方原文：[Developing a computer use model](https://www.anthropic.com/research/developing-computer-use)（Anthropic · Research）。

## 导读

这篇讲 Claude 3.5 Sonnet 的 Computer Use 是怎么训出来的：看用户屏幕的截图，按像素数出光标该移动多少，再点击、用虚拟键盘输入。训练只在计算器和文本编辑器这类简单软件上做，训练期间不让模型上网，它仍能把书面指令拆成一串动作，并在受阻时自己重试。能力边界写得很具体：OSWorld 上是 14.9%，人大约 70%–75%，同类别次优模型是 7.7%；拖拽、缩放还做不了，连环画式的截图也会漏掉一闪而过的通知。安全上，连网电脑的截图会把提示注入（prompt injection）带进模型。原文发表于 2024 年 10 月 22 日，当时处于公开测试。

## 译文

原文页标注发表于 2024 年 10 月 22 日，类别为 Product。主题包括 Computer Use、Claude Sonnet、训练、负责任扩展政策（Responsible Scaling Policy）、防护措施和基准测试。

Claude 现在可以使用电脑。[当时最新版本的 Claude 3.5 Sonnet](http://anthropic.com/news/3-5-models-and-computer-use) 在合适的软件环境里运行时，可以按用户的指令在电脑屏幕上移动光标、点击相关位置，并通过虚拟键盘输入信息，模仿人使用自己电脑的方式。

他们认为这项技能——当时处于公开测试（public beta）——是 AI 进展里的一次重要突破。下面分享的，是开发 Computer Use 模型、以及把它们做得更安全时，研究中的一些认识。

### 为什么要做 Computer Use

这项新能力为什么重要？大量现代工作都发生在电脑上。让 AI 以人使用软件的同一种方式直接与电脑软件交互，会打开当前这一代 AI 助手做不到的一大批应用。

过去几年，强大 AI 的开发到达过不少重要节点，例如完成复杂逻辑推理，以及看见并理解图像。下一道前沿是 Computer Use：模型不必再经由专门定制的工具来交互，而是被赋予能力，按指令去使用基本上任意一款软件。

### 研究过程

他们此前在工具使用和多模态（multimodality）上的工作，为这些新的 Computer Use 技能打下了基础。操作电脑需要看见并解释图像——这里是电脑屏幕的图像。它还要求根据屏幕上的内容，推理出应当在何时、以何种方式执行具体操作。把这些能力合在一起，他们训练 Claude 去解释屏幕上正在发生什么，再用可用的软件工具把任务做完。

开发者把某款电脑软件交给 Claude，并给它必要的访问权限之后，Claude 会查看用户所能看见的截图，然后数出光标在垂直或水平方向上需要移动多少像素，才能点中正确的位置。把 Claude 训练到能准确地数像素，这一点至关重要。没有这项技能，模型就很难给出鼠标指令——情形类似于模型常常答不好「单词 banana 里有几个 A」这种看起来很简单的问题。

他们感到意外的是，Claude 从很少几款简单软件上的 Computer Use 训练里泛化得很快，例如计算器和文本编辑器（出于安全，训练期间不允许模型访问互联网）。这项训练与 Claude 的其他技能合在一起，使它能够把用户写下的提示变成一串逻辑步骤，再在电脑上采取行动。他们观察到，模型遇到障碍时甚至会自己纠正并重试任务。

最初的突破一旦出现，后面的进展来得很快，但走到那一步经历了大量试错。一些研究者觉得，开发 Computer Use 很接近他们刚入行时想象的那种「理想化」的 AI 研究过程：不断迭代，一次次回到绘图板前，直到出现进展。

研究有了回报。就「以人使用电脑的方式使用电脑」的模型而言——也就是看着屏幕、再据此采取行动——当时的 Claude 处于该类别的最高水平。在一项用来检验开发者让模型使用电脑的评测 [OSWorld](https://os-world.github.io/) 上，Claude 当时得到 14.9%。这离人的水平还很远（人一般是 70%–75%），但远高于同一类别里次优 AI 模型的 7.7%。

### 让 Computer Use 更安全

AI 的每一次进展都带来新的安全挑战。Computer Use 主要是降低门槛，让 AI 系统去运用它们已经具备的认知技能，并不是从根本上提高这些技能，因此他们对 Computer Use 的主要关切集中在当下的伤害，而不是未来的伤害。他们通过评估 Computer Use 是否提高了[负责任扩展政策](https://www.anthropic.com/news/announcing-our-updated-responsible-scaling-policy)所列出的前沿威胁风险，确认了这一点。结果是：更新后的 Claude 3.5 Sonnet，连同它新的 Computer Use 技能，仍然处于 AI 安全等级 2（AI Safety Level 2）——也就是说，它并不要求比当时已经到位的安全和安保措施更高的标准。

未来的模型如果因为构成灾难性风险而需要 AI 安全等级 3 或 4 的防护，Computer Use 可能会加剧那些风险。他们的判断是，更合适的时机是现在就引入 Computer Use，此时模型仍然只需要 AI 安全等级 2 的防护。这样可以在利害还没有高到无法承受之前，就开始处理安全问题，而不是第一次把 Computer Use 加进一个风险严重得多的模型。

本着这一考虑，信任与安全（Trust & Safety）团队对新的 Computer Use 模型做了广泛分析，以找出潜在弱点。他们识别出的一个问题是提示注入（prompt injection）：这是一类网络攻击，把恶意指令送进 AI 模型，使它覆盖先前的指示，或者做出偏离用户原本意图的行动。由于 Claude 会解释来自联网电脑的截图，它有可能接触到包含提示注入攻击的内容。

在公开测试中使用 Claude 的 Computer Use 版本的人，应当采取相应预防措施，把这类风险压到最低。给开发者的资源是他们在[参考实现](https://github.com/anthropics/anthropic-quickstarts/tree/main/computer-use-demo)里提供的进一步指导。

和任何 AI 能力一样，用户也可能故意滥用 Claude 的电脑技能。他们的团队开发了分类器和其他方法，用来标记并缓解这类滥用。鉴于即将到来的美国选举，他们对那些可能被视为破坏公众对选举程序信任的滥用企图保持高度警惕。Computer Use 还没有先进到、也还不能以那样的规模运行，以至于相对既有能力构成更高的风险。尽管如此，他们已经采取措施，在 Claude 被要求从事与选举相关的活动时进行监测，并建立系统，引导 Claude 避开诸如在社交媒体上生成并发布内容、注册网站域名、或与政府网站交互这类活动。他们会在公开测试期间持续评估并迭代这些安全措施，在 Claude 的能力与负责任的使用之间取得平衡。

### Computer Use 的下一步

Computer Use 是一条完全不同的 AI 开发路径。在此之前，大语言模型（LLM）的开发者是让工具去迁就模型，做出定制环境，让 AI 用专门设计的工具完成各种任务。现在可以让模型去迁就工具——Claude 可以进入我们每个人每天都在用的电脑环境。他们的目标是让 Claude 拿起已经存在的电脑软件，简单地像人那样使用它们。

要做的事还很多。即便它是当时的最高水平，Claude 的 Computer Use 仍然慢，而且经常出错。人用电脑时常规会做的许多动作（拖拽、缩放等等），Claude 还无法尝试。Claude 看屏幕的方式是连环画式的（flipbook）：拍下截图再把它们拼起来，而不是观察更细粒度的视频流。因此它可能错过转瞬即逝的动作或通知。

就在为当天的发布录制 Computer Use 演示时，他们也遇到了一些滑稽的错误，见 [Anthropic 当时的帖子](https://x.com/AnthropicAI/status/1848742761278611504)。一次，Claude 不小心点停了一次长时间的屏幕录制，导致全部画面丢失。另一次，Claude 突然从编程演示里停下来，开始浏览黄石国家公园的照片。

他们预期 Computer Use 会很快变得更快、更可靠，也更适合用户想完成的任务。对软件开发经验较少的人来说，它也会变得容易实现得多。在每一个阶段，研究者都会与安全团队紧密合作，保证 Claude 的新能力伴随着相应的安全措施。

他们邀请在公开测试中试用 Computer Use 的开发者用[这张表](https://docs.google.com/forms/d/e/1FAIpQLSeD3IqITWsuepB19SEv889HsBvN9WOi6HRblPrJNyA9G7q02w/viewform)把反馈发给他们，以便研究者继续改进这项新能力的用处和安全性。

## 笔记

- 训练上被写成关键一步的是数像素。原文拿「banana 里有几个 A」作类比：数不准，鼠标指令就不可靠。泛化发生在很少几款离线软件之后，训练时明确不给互联网。
- 能力边界和评测写在一起：OSWorld 14.9%，人一般 70%–75%，同类别次优模型 7.7%。拖拽和缩放还不能做；截图拼接会漏掉短命的通知。发布演示里的两个失误是点停录屏，以及跑去看黄石的照片。
- 提示注入从联网电脑的截图进来，用户不必自己把恶意指令打进对话框。公开测试的开发者指导在参考实现里；人为滥用靠分类器，并监测选举相关活动，引导模型避开发社交媒体、注册域名和访问政府网站。
