## 导读

从 prompt engineering（提示词工程）走到 context engineering（上下文工程），关心的是整个上下文里放什么、何时放。文中会碰到 JIT（即时加载）、compaction（上下文压缩）和注意力预算。注意力有预算，把窗口塞满会冲掉真正要记住的内容。
